# 🏆 FIFA World Cup 2026 Dashboard | Power BI

## 📌 Project Overview

The **FIFA World Cup 2026 Dashboard** is an interactive data analytics project built using **Power BI** to provide a comprehensive overview of the tournament.

The project covers multiple aspects of the FIFA World Cup 2026, including:

- ⚽ Match Results
- 🥅 Goals & Scorers
- 🏆 Group Standings
- 🏟️ Stadiums & Attendance
- 👤 Top Goal Scorers
- 🌍 Participating Teams

Unlike a traditional Power BI dashboard, this project combines **data collection, web scraping, Python data processing, UI/UX design, and custom HTML/CSS visuals** to create a highly interactive and modern dashboard experience.

---

# 🎯 Project Objectives

The main objective of this project is to transform World Cup data into an interactive and visually engaging dashboard that helps users explore:

- Tournament performance
- Match statistics
- Goals and scoring trends
- Top-performing players
- Team performance
- Group standings
- Stadium capacities
- Match attendance
- Tournament insights

# 📂 Datasets

The project consists of **6 datasets** collected and prepared for analysis.

### 1️⃣ `world_cup_2026_all_goals`

Contains detailed information about goals scored during the tournament.

### 2️⃣ `world_cup_2026_full_dataset`

The main dataset containing comprehensive match-related information.

### 3️⃣ `world_cup_2026_group_standings`

Contains team performance and standings during the group stage.

### 4️⃣ `world_cup_2026_scorers`

Contains information about players and their scoring performance.

### 5️⃣ `world_cup_2026_stadiums`

Contains stadium information, including:

- Stadium names
- Host cities
- Stadium capacity
- Match attendance

### 6️⃣ `world_cup_2026_top_10_scorers`

Contains the ranking and statistics of the tournament's top 10 goal scorers.

# 🧹 Data Cleaning & Preparation

After collecting the raw data, the datasets were processed and cleaned using **Python**.

The data preparation process included:

- Removing duplicates
- Handling missing values
- Correcting data types
- Standardizing column names
- Cleaning inconsistent values
- Preparing datasets for analysis
- Creating structured datasets for Power BI

This step ensured that the data was accurate, organized, and ready for visualization.

# 🎨 Dashboard Design

Before developing the dashboard in Power BI, the complete layout and user interface were designed using **Figma**.

Each dashboard page was designed individually to maintain:

- Consistent colors
- Clear navigation
- Modern layout
- Better user experience
- Visual consistency across all pages

The final dashboard follows a modern **dark blue and gold theme** inspired by the FIFA World Cup identity.
